Restore configuration file discovery debug logging in magik-lint.

`--show-checks --debug` (and `--debug` in general) no longer showed where
`magik-lint` searched for and found (or did not find) its configuration
file. This was caused by `debug-logging.properties` explicitly silencing
`ConfigurationLocator` and `MagikToolsProperties` at `WARNING` level,
overriding the `--debug` flag. These overrides are removed, restoring the
0.12.1 behaviour.
