File should be in the load_list.

Why is this an issue?

If the file is a utility, to be loaded later on, move it to another directory.

Code examples

Non-compliant code example

Given a directory containing file1.magik, file2.magik, and file3.magik:

file1.magik
file2.magik

file3.magik exists on disk but is not listed in load_list.txt, so it will not be loaded.

Compliant solution

file1.magik
file2.magik
file3.magik
