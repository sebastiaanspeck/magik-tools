Exemplars should not have too many slots.

Why is this an issue?

Too many slots is an indication that an exemplar is having multiple responsibilities while it should have a single responsibility.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :example_exemplar,
    {
        {:slot1, _unset},
        {:slot2, _unset},
        {:slot3, _unset},
        {:slot4, _unset},
        {:slot5, _unset},
        {:slot6, _unset},
        {:slot7, _unset},
        {:slot8, _unset},
        {:slot9, _unset},
        {:slot10, _unset},
        {:slot11, _unset}
    })

This exemplar has 11 slots, exceeding the default maximum of 10.

Compliant solution

def_slotted_exemplar(
    :example_exemplar,
    {
        {:slot1, _unset},
        {:slot2, _unset},
        {:slot3, _unset}
    })

The remaining slots are moved to a related exemplar, keeping each exemplar focused on a single responsibility.
