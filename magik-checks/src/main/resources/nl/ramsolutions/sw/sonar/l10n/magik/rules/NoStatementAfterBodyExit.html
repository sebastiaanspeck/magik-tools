Statements after a body-exit statement are never executed.

Why is this an issue?

A _return, >>, _leave, or _continue immediately exits the enclosing construct, so any code written after it is unreachable dead code that can never run. It adds confusion for readers and is usually a sign that code was moved or the control flow changed without updating what follows.

Code examples

Non-compliant code example

_method a.b
  _return 10
  write(10)  # never executed
_endmethod
