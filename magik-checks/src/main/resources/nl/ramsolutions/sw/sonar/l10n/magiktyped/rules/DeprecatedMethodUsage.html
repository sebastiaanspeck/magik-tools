Deprecated method usage

Why is this an issue?

A method marked with _pragma(classify_level=deprecated) is intended to be removed or replaced. Calling it risks breaking when the deprecated method is eventually removed, and usually means a newer alternative should be used instead.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :exemplar,
    {})

_pragma(classify_level=deprecated)
_method exemplar.example_method()
_endmethod
$

_block
    _local exem << exemplar
    exem.example_method()
_endblock
$

Compliant solution

def_slotted_exemplar(
    :exemplar,
    {})

_method exemplar.example_method()
_endmethod
$

_block
    _local exem << exemplar
    exem.example_method()
_endblock
$

Without the _pragma(classify_level=deprecated) directive, calling example_method() no longer raises an issue.
