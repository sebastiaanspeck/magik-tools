Compare strings, bignums, and floats with the equality-operators, instead of the _is/_isnt operators.

Why is this an issue?

_is/_isnt compare object identity, while =/~= compare value. Two strings, bignums, or floats can hold the same value while being different objects, so _is can incorrectly report them as unequal even though = would consider them the same.

Code examples

Non-compliant code example

a _is "test"

Compliant solution

a = "test"
