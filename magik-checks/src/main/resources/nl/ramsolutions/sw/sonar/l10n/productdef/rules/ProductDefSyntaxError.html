product.def contains a syntax error.

Why is this an issue?

A product.def that does not parse cannot be loaded, so the product, and anything that depends on it, will fail to load until the syntax error is fixed.

Code examples

Non-compliant code example

example_product layered_product

titles
    An example product
end

Compliant solution

example_product layered_product

title
    An example product
end
