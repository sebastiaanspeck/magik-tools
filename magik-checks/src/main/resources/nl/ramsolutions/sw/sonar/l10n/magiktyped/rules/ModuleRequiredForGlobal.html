Module required for used global

Why is this an issue?

A global supplied by another module is only guaranteed to be loaded if the current module requires that module. Without the requires entry, the global may not exist yet at runtime, depending on load order.

Code examples

Non-compliant code example

# Inside a module which does NOT require the appropriate module to get
# the test_exemplar_from_another_module global variable.
_block
    _local var << test_exemplar_from_another_module
_endblock
$

Compliant solution

# Inside a module which requires the appropriate module to get
# the test_exemplar_from_another_module global variable.
_block
    _local var << test_exemplar_from_another_module
_endblock
$
