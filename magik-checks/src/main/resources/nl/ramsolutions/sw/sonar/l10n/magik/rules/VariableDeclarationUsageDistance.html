Distance between a variable declaration and its first usage.

Why is this an issue?

The further apart a variable's declaration and its first use are, the more a reader has to hold in mind, or scroll back to, in order to know what it holds by the time it's used. Keeping the declaration close to its first use makes the code easier to follow.

Code examples

Non-compliant code example, max distance is 5

_local a << 10
do_something_unrelated()  # distance to a is 1
do_something_unrelated()  # distance to a is 2
do_something_unrelated()  # distance to a is 3
do_something_unrelated()  # distance to a is 4
do_something_unrelated()  # distance to a is 5
show(a)                   # distance to a is 6
