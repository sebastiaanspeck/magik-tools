Method/procedure is too long.

Why is this an issue?

A long method usually does more than one thing, which makes it harder to understand, test, and safely change. Splitting it into smaller, well-named methods clarifies each responsibility.

Compliant solution

_endmethod

The logic is split into smaller, well-named helper methods.
