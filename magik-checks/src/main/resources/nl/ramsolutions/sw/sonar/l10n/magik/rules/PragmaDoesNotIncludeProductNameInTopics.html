Pragma does not contain the product name in the topics.

Why is this an issue?

Pragma topics are used by tooling, such as method_finder, to classify and filter definitions. When a definition's topics do not include the name of the product it lives in, that definition will not be found when filtering by that product, making it harder to discover.

Code examples

Given the next product.def:

example_product layered_product

description
	Example product
end

Non-compliant code example

_pragma(classify_level=basic, topic={something_else})
def_slotted_exemplar(:example, {})
$

Compliant solution

_pragma(classify_level=basic, topic={something_else, example_product})
def_slotted_exemplar(:example, {})
$
