Type-doc Type Exists

Why is this an issue?

A type referenced in a @param, @return, @slot, or @loop annotation that does not exist in the codebase cannot be resolved by the type checker, and the documentation misleads readers about what type is actually expected.

Code examples

Non-compliant code example

_method a.b(p1)
    ## @param {user:non_existing_exemplar} p1
    ## @return {user:non_existing_exemplar}
_endmethod

Compliant solution

_method a.b(p1)
    ## @param {sw:integer} p1
    ## @return {sw:integer}
_endmethod
