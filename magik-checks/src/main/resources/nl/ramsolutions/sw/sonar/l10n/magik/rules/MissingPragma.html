Definition is missing a pragma declaration.

Why is this an issue?

A pragma declares metadata about a definition, such as its classify_level, topic, and intended usage (e.g. whether it may be redefined or subclassed). Without it, tooling such as method_finder cannot classify the definition, and its intended usage towards other developers is undocumented.

Code examples

Non-compliant code example

_method object.do_something(param1)
_endmethod

Compliant solution

_pragma(classify_level=basic, topic={example}, usage=redefinable)
_method object.do_something(param1)
_endmethod
