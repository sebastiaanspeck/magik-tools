If the left hand side and right hand side of a comparison are the same, the result is always true.

Why is this an issue?

A comparison where both sides are the same expression always evaluates to the same result, so it adds no real logic and usually indicates a typo, such as comparing a variable to itself instead of to the value that was intended.

Code examples

Non-compliant code example

_if "abc" = "abc"
_then
  ...
_endif
