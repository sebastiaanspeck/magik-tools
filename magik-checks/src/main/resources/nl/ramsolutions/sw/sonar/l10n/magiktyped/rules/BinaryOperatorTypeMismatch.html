Binary operator type mismatch

Why is this an issue?

Applying a binary operator to a combination of types that does not define it, such as + between sw:symbol and sw:integer, is not a defined operation and results in a runtime error.

Code examples

Non-compliant code example

_method a.b
    _local x << :symbol
    _local y << :symbol + 1
    x +<< 1
_endmethod

Compliant solution

_method a.b
    _local x << 1
    _local y << x + 1
    x +<< 1
_endmethod
