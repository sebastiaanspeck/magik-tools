Methods/Procedures should not have too many parameters.

Why is this an issue?

A long parameter list is hard to call correctly and to read at the call site, since it's easy to mix up the order or forget an argument. It often also indicates the method is doing too much and could be split, or that the parameters belong together in their own object.

Code examples

Non-compliant code example

_method object.example(p1, p2, p3, p4, p5, p6, p7)
_endmethod

_proc@example_proc(p1, p2, p3, p4, p5, p6, p7)
_endproc
