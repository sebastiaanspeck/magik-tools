Block is empty and can be removed.

Why is this an issue?

An empty block does nothing, so its presence usually means the intended implementation was never written, or was removed during a refactor and the empty shell was left behind. Either way it adds noise without a purpose.

Code examples

Non-compliant code example

_if a
_then
  write(a)
_else
  # block without any contents
_endif

Compliant solution

_if a
_then
  write(a)
_endif
