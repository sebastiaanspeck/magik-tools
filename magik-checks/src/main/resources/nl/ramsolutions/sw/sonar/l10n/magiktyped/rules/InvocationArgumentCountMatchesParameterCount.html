Invocation argument count matches parameter count

Why is this an issue?

Calling a method or procedure with fewer or more arguments than it declares will result in a runtime error.

Code examples

Non-compliant code example

_method a.m(param1, param2)
_endmethod
$

_block
    a.m(1)
_endblock
$

Compliant solution

_method a.m(param1, param2)
_endmethod
$

_block
    a.m(1, 2)
_endblock
$
