Pragma topic does not contain all the required configured topics.

Why is this an issue?

Pragma topics are used by tooling, such as method_finder, to classify and filter definitions. A project can configure this check to require one or more specific topics on every definition, enforcing its own classification scheme. When a definition is missing a required topic, it will not be found when filtering by that topic, making it harder to discover.

Code examples

Given the next configuration:

pragma-does-not-include-topic-in-topics.topics=magik

Non-compliant code example

_pragma(classify_level=basic, topic={something_else})
def_slotted_exemplar(:example, {})
$

Compliant solution

_pragma(classify_level=basic, topic={something_else, magik})
def_slotted_exemplar(:example, {})
$
