Abstract method not implemented

Why is this an issue?

When a class inherits an abstract method but does not implement it, calling that method through an instance of the class results in a runtime error.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :parent,
    {})

_abstract _method parent.do_something()
    ## @return {sw:integer}
_endmethod

def_slotted_exemplar(
    :child,
    {},
    :parent)

_method child.other_method()
    _return 1
_endmethod

Compliant solution

def_slotted_exemplar(
    :parent,
    {})

_abstract _method parent.do_something()
    ## @return {sw:integer}
_endmethod

def_slotted_exemplar(
    :child,
    {},
    :parent)

_method child.do_something()
    ## @return {sw:integer}
    _return 1
_endmethod

child now implements the abstract method it inherited from parent.
