Variadic ('Type...') is only valid on @return or @loop

Why is this an issue?

The variadic marker ... describes "zero or more values of T". It is meaningful on @return (a method returning 0..N values) and on @loop (a _loopbody emitting 0..N values per iteration), but not on @param or @slot.

Code examples

Variadic on @param (raises an issue)

_method example_exemplar.example_method(_gather args)
    ## @param {sw:integer...} args
_endmethod

Correct: declare the element type (no issue)

_method example_exemplar.example_method(_gather args)
    ## @param {sw:integer} args
_endmethod

Variadic on @return or @loop (no issue)

_iter _method example_exemplar.example_iter()
    ## @loop {sw:integer...}
    _loopbody(1)
_endmethod
