Pragma contains an invalid usage.

Why is this an issue?

The usage value tells other developers, and tooling, whether a definition may be redefined, subclassed, or is for external/internal use. An invalid value is not recognized, so that guidance is effectively missing.

Code examples

Non-compliant code example

_pragma(classify_level=basic, topic={example}, usage=invalid)
_method object.do_something()
_endmethod

Compliant solution

_pragma(classify_level=basic, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

The usage should be one of:

  • subclassable
  • subclass
  • redefinable
Other known, but to be ignored, usages are:
  • external
  • internal
