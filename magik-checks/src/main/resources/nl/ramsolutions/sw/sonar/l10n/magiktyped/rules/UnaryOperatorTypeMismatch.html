Unary operator type mismatch

Why is this an issue?

A unary operator such as + maps to a method (e.g. unary_plus). When that method is not defined for the operand's type, applying the operator results in a runtime error.

Code examples

Non-compliant code example

_method a.b
    _local x << :symbol
    _local y << +x
_endmethod

Compliant solution

_method a.b
    _local x << 1
    _local y << +x
_endmethod
