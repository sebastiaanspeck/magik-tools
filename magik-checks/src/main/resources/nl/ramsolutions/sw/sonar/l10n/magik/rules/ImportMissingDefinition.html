Import missing definition.

Why is this an issue?

An _imported name must already exist in an enclosing scope; the statement makes that outer variable available inside the nested procedure, it does not create a new one. Importing a name that is not defined anywhere outside is a typo or leftover from refactoring, and fails or misbehaves at runtime.

Code examples

Non-compliant code example

_method exemplar.method
  _proc@nested_proc()
    _import missing_var
  _endproc
_endmethod
