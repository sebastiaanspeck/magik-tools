No self usage.

Why is this an issue?

When _self is not used, should this actually be a method? This might indicate a design issue, although this does not always have to be the case.

Code examples

Non-compliant code example

_method exemplar.write_info()
  write("This is info about me")
_endmethod

Compliant solution

_method exemplar.write_info()
  write("This is: ", _self)
_endmethod
