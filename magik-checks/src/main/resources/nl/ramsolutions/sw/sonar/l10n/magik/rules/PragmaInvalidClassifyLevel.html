Pragma contains an invalid classify_level.

Why is this an issue?

The classify_level controls how tooling such as method_finder groups and filters a definition (e.g. hiding advanced or deprecated definitions from a basic search). An invalid value is not recognized by that tooling, so the definition is not classified correctly.

Code examples

Non-compliant code example

_pragma(classify_level=invalid, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

Compliant solution

_pragma(classify_level=basic, topic={example}, usage=redefinable)
_method object.do_something()
_endmethod

The classify_level should be one of:

  • basic
  • advanced
  • restricted
  • debug
  • deprecated
