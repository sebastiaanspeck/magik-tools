Use of sw:char16_vector.evaluate()

Why is this an issue?

Using sw:char16_vector.evaluate() to execute a string as Magik code is dangerous when that string comes from user input, as it can lead to code injection vulnerabilities if the input is not properly sanitized.

Code examples

Non-compliant code example

_method exemplar.example_method()
    _local user_input << "gis_program_manager.cached_dataset(:gis).collection(:very_important_data).empty()"
    user_input.evaluate()
_endmethod

Compliant solution

_method exemplar.example_method()
    _local user_input << "gis_program_manager.cached_dataset(:gis).collection(:very_important_data).empty()"
    user_input.sandboxed_evaluate()
_endmethod

sandboxed_evaluate() runs the expression without access to global values, eliminating the risk of accessing session state or variables.
