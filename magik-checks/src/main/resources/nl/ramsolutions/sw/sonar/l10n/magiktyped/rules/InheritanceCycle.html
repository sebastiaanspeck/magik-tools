Inheritance cycle

Why is this an issue?

A type cannot legitimately inherit from itself, directly or indirectly. When two or more exemplars inherit from each other, forming a cycle, resolving methods/slots for any of the involved types is undefined. This cycle can be spread across separate files/modules, so neither file necessarily looks wrong on its own.

Code examples

Non-compliant code example

def_slotted_exemplar(:child, {}, :parent)
$

def_slotted_exemplar(:parent, {}, :child)
$

Compliant solution

def_slotted_exemplar(:child, {}, :parent)
$

def_slotted_exemplar(:parent, {})
$

child inherits from parent, but parent no longer inherits from child, breaking the cycle.
