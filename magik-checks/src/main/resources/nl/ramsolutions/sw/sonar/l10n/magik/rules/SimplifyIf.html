This if-statement can be simplified.

Why is this an issue?

A _then/_else-nested _if that only contains another _if can be flattened using _elif, which reads more clearly and reduces the nesting a reader has to track mentally.

Code examples

Non-compliant code example

_if a
_then
  write(1)
_else
  _if b
  _then
    write(2)
  _endif
_endif

Compliant solution

_if a
_then
  write(1)
_elif b
_then
  write(2)
_endif
