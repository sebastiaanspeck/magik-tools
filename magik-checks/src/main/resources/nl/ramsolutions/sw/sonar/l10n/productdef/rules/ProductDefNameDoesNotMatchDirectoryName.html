Product name does not match the directory name.

Why is this an issue?

Tooling that locates a product by its directory expects the declared name to match. A mismatch can make the product harder to find, or cause inconsistent behavior between tools that look it up by name versus by directory.

Code examples

Non-compliant code example

Given a product in a directory named example_product:

different_name layered_product

Compliant solution

example_product layered_product
