Conditional expression does not result in true/false

Why is this an issue?

In Magik, conditional expressions should result in a boolean value (true or false), otherwise this will result in an error. A type that responds to should_be_boolean() is also accepted, as Magik will use that method to coerce the value to a boolean.

Code examples

Non-compliant code example

_if :a
_then
_endif

Compliant solution

_if 1 = 1
_then
_endif
