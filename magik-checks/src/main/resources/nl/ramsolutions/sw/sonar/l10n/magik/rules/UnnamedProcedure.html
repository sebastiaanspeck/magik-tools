Procedures should have a name.

Why is this an issue?

A name makes a procedure better identifiable in tracebacks and other output. Add a name using the @name syntax: _proc @name() _endproc.

Code examples

Non-compliant code example

_proc(string)
  >> string.uppercase
_endproc

Compliant solution

_proc @uppercase(name)
  >> name.uppercase
_endproc
