Method is defined multiple times in the same file.

Why is this an issue?

When the same method is defined more than once in a file, only the last definition takes effect; the earlier one is silently discarded. This is usually a copy-paste mistake and can hide a change that was intended to apply.

Code examples

Non-compliant code example

_method exemplar.calculate_total()
    _return 1
_endmethod

_method exemplar.calculate_total()
    _return 2
_endmethod

Only the second definition of calculate_total() takes effect; the first is silently discarded.

Compliant solution

_method exemplar.calculate_total()
    _return 2
_endmethod
