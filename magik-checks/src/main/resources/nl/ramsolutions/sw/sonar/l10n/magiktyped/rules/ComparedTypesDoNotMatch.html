Compared types do not match

Why is this an issue?

Comparing a value to a type it can never actually be, based on its documented type, produces a condition that can never be true, which is usually a sign the comparison, or the type documentation, does not reflect what the code is meant to check.

Code examples

Non-compliant code example

_method a.m(param1)
    ## @param {sw:integer} param1
    _if param1 _is _unset
    _then
        # This condition will never be true, since param1 is defined as sw:integer,
        # and can therefore never be sw:unset.
    _endif
_endmethod
$

Compliant solution

_method a.m(param1)
    ## @param {sw:integer|sw:unset} param1
    _if param1 _is _unset
    _then
        # This condition can be true, since param1 may be sw:unset.
    _endif
_endmethod
$

param1 is now documented as sw:integer|sw:unset, so comparing it to _unset is meaningful.
