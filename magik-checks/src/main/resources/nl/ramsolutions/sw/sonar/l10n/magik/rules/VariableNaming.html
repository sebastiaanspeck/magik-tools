Give variable a proper descriptive name, consisting of a least 3 characters and a maximum of 32 characters (excluding prefix).

Non-compliant Code Example

_local a << 1
_local l_b << 1
_local a_very_long_variable_name_that_is_not_descriptive_anymore << 1

Compliant Code Example

_local count << 1
_local index << 1
_local total << 1

If you have enabled forbidding scope prefixes, variable and parameter names may not start with p_, l_, i_ or c_ either.

Non-compliant Code Example

_local l_count << 1

Compliant Code Example

_local count << 1
