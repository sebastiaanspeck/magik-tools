Give variable a proper descriptive name, consisting of a least 3 characters and a maximum of 32 characters (excluding prefix).

Why is this an issue?

Short or overly long variable names make code harder to read: a name like a gives no clue what it holds, forcing the reader to trace its usage, while an excessively long name adds noise without adding clarity.

Code examples

Non-compliant code example

_method exemplar.example_method()
    _local a << 1
    _local l_b << 1
    _local a_very_long_variable_name_that_is_not_descriptive_anymore << 1
_endmethod

Compliant solution

_method exemplar.example_method()
    _local count << 1
    _local index << 1
    _local total << 1
_endmethod
