Multiple assignment count mismatch

Why is this an issue?

When a multiple assignment has more target variables than the expression returns values, the extra variables silently receive _unset instead of raising an error, which can hide a bug.

Code examples

Non-compliant code example

_method a.b
    (x, y, z) << (1, 2)
_endmethod

Compliant solution

_method a.b
    (x, y, z) << (1, 2, 3)
_endmethod
