Method/procedure/slotted exemplar is missing documentation.

Why is this an issue?

Free-text comments describing parameters, return values, and slots cannot be interpreted by tooling, and tend to go stale as code changes. @param, @return, @slot, and @loop annotations give the same information in a form the type checker can verify, so mismatches between what a method documents and what it actually does are caught during linting instead of at runtime.

Code examples

Non-compliant code example

_method object.do_something(param1)
  ## This method does something.
  ## Then it returns _true.
  _return _true
_endmethod

Compliant solution

_method object.do_something(param1)
  ## This method does something.
  ## @param {sw:char16_vector} param1 This parameter is used to do domething.
  ## @return {sw:false} True if successful, false if not.
  _return _true
_endmethod

Non-compliant code example

def_slotted_exemplar(
  :test_exemplar,
  {
    {:slot1, _unset}
  })

Compliant solution

## @slot {sw:rope} slot1 Slot 1.
def_slotted_exemplar(
  :test_exemplar,
  {
    {:slot1, _unset}
  })
