Method Is Public

Why is this an issue?

A private method can only be called from within its own definition. Calling it from anywhere else results in a runtime error.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :example_exemplar,
    {})

_private _method example_exemplar.private_example_method()
    ## Private method which cannot be called from other methods or blocks.
_endmethod
$

_block
    example_exemplar.private_example_method()
_endblock
$

Compliant solution

def_slotted_exemplar(
    :example_exemplar,
    {})

_method example_exemplar.public_example_method()
    ## Public method which can be called from other methods or blocks.
_endmethod
$

_block
    example_exemplar.public_example_method()
_endblock
$
