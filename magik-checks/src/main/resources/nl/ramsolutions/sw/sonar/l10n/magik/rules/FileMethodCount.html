Files should not contain too many methods.

Why is this an issue?

Too many methods in a file is an indication that the unit is too complex. Consider breaking up the unit.

Code examples

Non-compliant code example

_method exemplar.method_1()
_endmethod

_method exemplar.method_2()
_endmethod

_method exemplar.method_3()
_endmethod

_method exemplar.method_4()
_endmethod

_method exemplar.method_5()
_endmethod

_method exemplar.method_6()
_endmethod

_method exemplar.method_7()
_endmethod

_method exemplar.method_8()
_endmethod

_method exemplar.method_9()
_endmethod

_method exemplar.method_10()
_endmethod

_method exemplar.method_11()
_endmethod

This file defines 11 methods, exceeding the default maximum of 10.

Compliant solution

_method exemplar.method_1()
_endmethod

_method exemplar.method_2()
_endmethod

The remaining methods are moved to another file, grouped by responsibility.
