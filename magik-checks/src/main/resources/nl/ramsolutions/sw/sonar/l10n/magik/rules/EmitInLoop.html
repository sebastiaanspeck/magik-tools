An emit statement (>>) inside a loop body has no effect.

Why is this an issue?

An emit only becomes the result of the block it directly belongs to. A _loop body's emits do not become the result of the loop itself, a loop only produces a value via _leave _with, so an emit inside a loop body is silently ignored.

Code examples

Non-compliant code example

_method a.b
  _local loop_val <<
    _for element _over collection.fast_elements()
    _loop
      >> element
    _endloop
  show(loop_val)  # loop_val is always _unset, emits have no effect.
_endmethod

Compliant solution

_method a.b
  _local loop_val <<
    _for element _over collection.fast_elements()
    _loop
      _leave _with element
    _endloop
  show(loop_val)  # loop_val has a value from the first iteration of the loop.
_endmethod
