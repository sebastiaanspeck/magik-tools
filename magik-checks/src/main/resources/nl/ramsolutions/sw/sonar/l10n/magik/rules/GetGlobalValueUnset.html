Guarding get_global_value() with _isnt _unset silently swallows the case where the global does not exist, instead of failing loudly. This is sometimes used as a hack to work around module load-order issues, but it hides real bugs when the global is missing for another reason.

Only the _isnt _unset form is flagged. _is _unset is not, since that branch may already fail loudly (e.g. by raising a condition) and this check cannot know how it is handled.

Non-compliant Code Example

_if (foo << get_global_value(:var)) _isnt _unset
_then
    foo.run()
_endif

Compliant Code Example

(foo << get_global_value(:var)).run()
