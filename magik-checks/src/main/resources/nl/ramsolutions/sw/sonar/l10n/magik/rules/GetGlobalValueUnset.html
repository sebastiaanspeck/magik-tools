Testing the result of get_global_value() against _unset silently swallows the case where the global does not exist, instead of failing loudly. This is sometimes used as a hack to work around module load-order issues, but it hides real bugs when the global is missing for another reason.

Non-compliant Code Example

_if (foo << get_global_value(:var)) _isnt _unset
_then
    foo.run()
_endif

Compliant Code Example

(foo << get_global_value(:var)).run()
