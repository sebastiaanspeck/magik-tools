Undefined method call result

Why is this an issue?

When a called method's return type is unknown, the type checker cannot verify how the result is subsequently used, which can hide type mismatches later in the code. Add @return type-doc to the method, or to the type database, to make this checkable.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :example_exemplar,
    {})

_method example_exemplar.undefined_method_call_result_example()
    _return unknown_exemplar.unknown_method()
_endmethod

_block
    _local var << example_exemplar.undefined_method_call_result_example()
_endblock
$

Compliant solution

def_slotted_exemplar(
    :example_exemplar,
    {})

_method example_exemplar.documented_method_call_result_example()
    ## @return {sw:integer} Result.
    _return 1
_endmethod

_block
    _local var << example_exemplar.documented_method_call_result_example()
_endblock
$
