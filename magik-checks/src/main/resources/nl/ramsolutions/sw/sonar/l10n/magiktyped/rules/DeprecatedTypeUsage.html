Deprecated type usage

Why is this an issue?

An exemplar marked with _pragma(classify_level=deprecated) is intended to be removed or replaced. Using it risks breaking when the deprecated exemplar is eventually removed, and usually means a newer alternative should be used instead.

Code examples

Non-compliant code example

_pragma(classify_level=deprecated)
## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
        })
$

_block
    example_exemplar.example_method()
_endblock
$

Compliant solution

## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
        })
$

_block
    example_exemplar.example_method()
_endblock
$

Without the _pragma(classify_level=deprecated) directive on example_exemplar, using it no longer raises an issue.
