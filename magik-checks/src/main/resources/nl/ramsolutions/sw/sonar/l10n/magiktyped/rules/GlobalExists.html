Global exists

Why is this an issue?

Referring to a global that does not exist will result in a runtime error as soon as that code path is executed.

Code examples

Non-compliant code example

_block
    # non_existing_exemplar is a non-existing global/exemplar.
    _local var << non_existing_exemplar.new()
_endblock
$

Compliant solution

_block
    _local var << rope.new()
_endblock
$

rope is an existing global.
