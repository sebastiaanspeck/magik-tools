Type annotation contains mixed generic definitions and references in a single generic parameter list.

Why is this an issue?

A generic parameter list should contain either all definitions (e.g., <K=sw:symbol, V=sw:object>) or all references (e.g., <E>), but not a mix of both.

Code examples

Non-compliant code example

_method object.do_something()
  ## @return {sw:property_list<K=sw:symbol,object>} Result.
  _return sw:property_list.new()
_endmethod

Compliant solution

_method object.do_something()
  ## @return {sw:property_list<K=sw:symbol, V=sw:object>} Result.
  _return sw:property_list.new()
_endmethod
