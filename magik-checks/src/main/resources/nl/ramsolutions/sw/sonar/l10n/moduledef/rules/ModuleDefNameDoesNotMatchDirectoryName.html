Module name does not match the directory name.

Why is this an issue?

Tooling that locates a module by its directory expects the declared name to match. A mismatch can make the module harder to find, or cause inconsistent behavior between tools that look it up by name versus by directory.

Code examples

Non-compliant code example

Given a module in a directory named example_module:

different_name 1

Compliant solution

example_module 1
