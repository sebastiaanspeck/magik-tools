Variadic @return / @loop must be the last entry of its kind

Why is this an issue?

A variadic @return or @loop annotation (a type ending in ...) represents zero or more trailing values. Only the last entry of each kind may be variadic; any earlier entry must specify a single non-variadic type.

Code examples

Variadic @return in non-last position (raises an issue)

_method example_exemplar.example_method()
    ## @return {sw:integer...} variadic, but not last
    ## @return {sw:symbol} after variadic
_endmethod

Variadic @return as the last (no issue)

_method example_exemplar.example_method()
    ## @return {sw:symbol} a fixed value
    ## @return {sw:integer...} variadic tail
_endmethod

Variadic @loop in non-last position (raises an issue)

_iter _method example_exemplar.example_iter()
    ## @loop {sw:integer...} variadic, but not last
    ## @loop {sw:symbol} after variadic
    _loopbody(1, :a)
_endmethod
