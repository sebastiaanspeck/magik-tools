load_list.txt or patch_list.txt contains a syntax error.

Why is this an issue?

Load list files should contain one file path per line, with optional comments starting with #.

Code examples

Non-compliant code example

# Load list example
file1.magik
file2.magik
invalid syntax here that doesn't parse

Compliant solution

# Load list example
file1.magik
file2.magik
# This is a valid comment
subdir/file3.magik
