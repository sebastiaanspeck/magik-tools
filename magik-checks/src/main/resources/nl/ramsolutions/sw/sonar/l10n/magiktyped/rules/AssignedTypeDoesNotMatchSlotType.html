Assigned type does not match slot type

Why is this an issue?

Assigning a value to a slot whose declared type does not accept that value's type means the slot's actual contents no longer match what its documentation promises.

Code examples

Non-compliant code example

## Example exemplar.
## @slot {sw:integer} slot_1
def_slotted_exemplar(
        :example_exemplar,
        {
            {:slot_1, 0}
        })

_method example_exemplar.example_method()
    ## This assignment will raise an issue, because slot_1 is declared as sw:integer, but we are assigning an sw:symbol.
    .slot_1 << :a_symbol
_endmethod
$

Compliant solution

## Example exemplar.
## @slot {sw:integer} slot_1
def_slotted_exemplar(
        :example_exemplar,
        {
            {:slot_1, 0}
        })

_method example_exemplar.example_method()
    .slot_1 << 12345
_endmethod
$
