Super method exists

Why is this an issue?

Calling _super with a method that does not exist on the parent type will result in a runtime error.

Code examples

Non-compliant code example

def_slotted_exemplar(
    :parent,
    {})

def_slotted_exemplar(
    :child,
    {},
    :parent)

_method child.do_something()
    _super.nonexistent()
_endmethod

Compliant solution

def_slotted_exemplar(
    :parent,
    {})

def_slotted_exemplar(
    :child,
    {},
    :parent)

_method parent.do_something()
_endmethod

_method child.do_something()
    _super.do_something()
_endmethod
