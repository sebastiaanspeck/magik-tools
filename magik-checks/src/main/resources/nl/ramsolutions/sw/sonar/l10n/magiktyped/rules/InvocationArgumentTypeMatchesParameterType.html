Invocation argument type does not match parameter type

Why is this an issue?

Calling a method or procedure with an argument whose type does not match what the callable documents can result in a runtime error inside the callable, since it was not written to handle that type.

Code examples

Non-compliant code example

_method a.m(param1, param2)
    ## @param {sw:integer} param1
    ## @param {sw:integer} param2
_endmethod
$

_block
    a.m(1, :a)
_endblock
$

Compliant solution

_method a.m(param1, param2)
    ## @param {sw:integer} param1
    ## @param {sw:integer} param2
_endmethod
$

_block
    a.m(1, 2)
_endblock
$
