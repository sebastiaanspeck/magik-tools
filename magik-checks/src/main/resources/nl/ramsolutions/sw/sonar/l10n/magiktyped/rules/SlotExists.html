Slot Exists

Why is this an issue?

Assigning to or reading a slot that is not defined on the exemplar will result in a runtime error.

Code examples

Non-compliant code example

## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
            {:slot_a, _unset}
        })

_method example_exemplar.example_method()
    ## This assignment will raise an issue, because slot_1 does not exist.
    .slot_1 << 12345
_endmethod
$

Compliant solution

## Example exemplar.
def_slotted_exemplar(
        :example_exemplar,
        {
            {:slot_a, _unset}
        })

_method example_exemplar.example_method()
    .slot_a << 12345
_endmethod
$
