Warned call.

Why is this an issue?

A project can configure this check with the specific calls it wants flagged, by default calls such as write(), remex(), and remove_exemplar(), calls that are either meant for temporary debugging or are destructive, so they shouldn't be left in committed code without a good reason.

Code examples

Non-compliant code example

write(variable)
remex(:exemplar)
remove_exemplar(:exemplar)
