A method should not be made _private when an ancestor defines it as public.

Non-compliant Code Example

_method parent.name
    >> :parent
_endmethod
$

_private _method child.name
    >> :child
_endmethod

Compliant Code Example

_method parent.name
    >> :parent
_endmethod
$

_method child.name
    >> :child
_endmethod

Code that holds a reference typed as parent can call name without knowing it actually received a child. Making the overriding method private breaks that contract: the call compiles against the ancestor's public method, but fails at runtime with a "not accessible" error, violating the Liskov Substitution Principle.

This mirrors SonarQube's S2638 rule ("visibility should not be reduced").
